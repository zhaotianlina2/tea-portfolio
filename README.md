# 赵天林｜下午茶主题互动作品集

这是一个以「下午茶餐桌」为视觉隐喻的个人作品集 Demo：访客通过茶具与甜点组成的互动场景浏览精选创作，而不是从传统项目列表开始。

## 页面里有什么

- **餐桌首页**：以茶壶、茶杯、餐盘和拼布桌布构成主视觉；标题区域可触发甜点动画。
- **茶杯作品画廊**：点击茶杯可查看旋转木马台灯、云端挂钟、织物纹样工坊、声音明信片和桌面花园等作品条目。
- **蛋糕作品画廊**：通过蛋糕切片进入 AIGC 短片《奥德赛的一天》、提示词炼金术和手作纹样图书馆等条目。
- **作品详情**：提供返回操作、文字介绍和对应的 SVG 视觉演示；页面还包含茶壶移动、倒茶、茶杯填充、悬停反馈与合成音效等交互。

以上是页面代码中呈现的作品名称和演示内容；仓库未提供独立项目链接或外部作品资料，因此本 README 不将其描述为可在线使用的完整产品。

## 设计与交互

整体采用复古下午茶配色、桌布纹样、餐具与甜点插画。主要插画和纹样以页面内嵌 SVG 绘制，场景通过 CSS 过渡切换，并配有悬停、点击、动画和 Web Audio 合成音效。页面针对窄屏设置了详情页布局调整，也包含减少动态效果的系统偏好处理。

## 技术实现

- 原生 HTML、CSS 与 JavaScript，页面、样式、SVG 图形和交互均集中在 `index.html`。
- 使用浏览器原生 SVG、CSS 动画/媒体查询与 Web Audio API；没有发现框架、包管理器或依赖清单。
- 页面通过 Google Fonts 加载 Playball 与 Noto Serif SC 字体；未连接网络时会使用字体回退。

## 本地查看

无需安装 JavaScript 依赖。直接在现代浏览器中打开仓库根目录的 `index.html` 即可查看页面；若浏览器限制本地文件行为，可从仓库目录启动任意静态文件服务器，再访问其提供的页面地址。Google Fonts 字体需要网络连接，其他主要图形由页面内嵌 SVG 提供。

仓库包含一个手动触发的 GitHub Pages 部署工作流；它会将 `index.html` 作为站点发布。本次检查只确认了工作流配置，不代表网站已部署或当前可访问。
